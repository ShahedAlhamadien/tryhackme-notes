## Overview

Defensive Security focuses on protecting systems, detecting attacks, and stopping suspicious activities.

## Key Terms

**SOC** = Security Operations Center, a team that monitors and investigates security alerts.

**SIEM** = A tool that collects and analyses security logs.

**Firewall** = A security system that controls network traffic.

**Containment** = Stopping an ongoing attack from causing more damage.

## Attack Steps

1. Opened the lab and reviewed the monitoring dashboard.
2. Opened the "URL Discovery Attempts" list to investigate the attack.
3. Moved to the "Stop the Attack" task.
4. Entered the attacker's IP address: `32.122.195.63`.
5. Changed the firewall action from `ALLOW` to `BLOCK`.
6. Clicked **Apply** to block the IP address.

## Final Note

Defensive Security helps protect systems by detecting suspicious activities, investigating attacks, and blocking malicious traffic. A firewall is one of the tools used to help stop attacks.
